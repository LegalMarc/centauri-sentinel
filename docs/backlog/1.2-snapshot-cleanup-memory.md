# Unbounded Memory Allocation in Database Snapshot Cleanup

**ID:** 1.2
**Severity:** Medium
**Category:** Performance
**Status:** Closed

## Affected Files
- `sentinel/db/repo.py`

## Description
Unbounded memory allocation during database snapshot cleanup. Querying all database snapshot paths into memory at once causes memory spikes when there are a large number of database rows.

## Evidence
- Database query loads all snapshot records into memory in a single query instead of batching or querying only needed metadata.

## Impact
- High memory consumption on large databases, leading to slowdowns or crashes on resource-constrained host devices.

- [x] Implement batching or streaming for snapshot cleanup queries
- [x] Verify memory usage stays low during cleanup execution
- [x] Add tests with thousands of snapshot records
