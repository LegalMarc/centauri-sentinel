# User Enumeration via Basic Authentication Timing Oracle

**ID:** 3.6
**Severity:** Low
**Category:** Security
**Status:** Closed

## Affected Files
- `sentinel/web/auth.py`

## Description
Authentication check returns immediately when username is invalid but performs expensive bcrypt verification when username is valid, creating a timing oracle.

## Evidence
- Bcrypt check is skipped entirely when the username does not exist in settings.

## Impact
- Allows attackers to determine if a username exists based on response times.

## Acceptance Criteria
- [x] Perform a dummy bcrypt verification on invalid usernames to keep response timing uniform
- [x] Verify timing is identical for valid vs invalid usernames
- [x] Tests pass
- [x] Coverage maintained ≥ 85%
