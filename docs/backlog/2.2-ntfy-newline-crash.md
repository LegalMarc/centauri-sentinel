# ntfy Notifier Crashes Due to Newline Characters in HTTP Headers

**ID:** 2.2
**Severity:** Medium
**Category:** Bugs
**Status:** Closed

## Affected Files
- `sentinel/notify/ntfy.py`

## Description
The ntfy notifier passes message titles or bodies in HTTP headers (e.g. X-Title). Newlines in these fields crash the HTTP client.

## Evidence
- Raw multiline strings are formatted directly into ntfy headers without sanitization or header encoding.

## Impact
- Crashes the notifier loop when sending alert notifications containing formatting or newlines.

## Acceptance Criteria
- [x] Sanitize or strip newline characters from all HTTP headers sent to ntfy
- [x] Test notifier with multiline alert messages and verify successful delivery
- [x] Tests pass
- [x] Coverage maintained ≥ 85%
