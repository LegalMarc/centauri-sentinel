# Printer Offline State Masks Complete Detection Halts

**ID:** 4.2
**Severity:** Medium
**Category:** Maintainability
**Status:** Closed

## Affected Files
- `sentinel/watcher/loop.py`

## Description
When the printer goes offline, the watcher transitions to OFFLINE, masking complete detection stalls or loop crashes.

## Evidence
- Watcher state transitions hide internal watchdog status.

## Impact
- Operators do not receive alerts if the watcher itself crashes vs when the printer is offline.

## Acceptance Criteria
- [x] Distinguish clearly between watcher loop stalls and printer connection drops
- [x] Ensure liveness watchdog fires even in offline state
- [x] Tests pass
- [x] Coverage maintained ≥ 85%
