# Privacy Risk: Unencrypted Exposure via Public Ntfy Topics

**ID:** 3.4
**Severity:** Medium
**Category:** Security
**Status:** Closed

## Affected Files
- `sentinel/notify/ntfy.py`

## Description
Sending detailed notifications (including camera snapshots) to public ntfy topics exposes private images of the user's room to anyone.

## Evidence
- Default settings encourage public ntfy.sh servers and public topic names without warning users about visibility.

## Impact
- Privacy leakage where third parties can monitor snapshots of the user's printer and surrounding environment.

## Acceptance Criteria
- [x] Enforce token auth for public ntfy domains or warn loudly in config
- [x] Document privacy implications of using unauthenticated public topics
- [x] Tests pass
- [x] Coverage maintained ≥ 85%
