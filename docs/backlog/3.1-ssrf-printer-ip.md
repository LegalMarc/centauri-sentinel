# Server-Side Request Forgery via Printer IP Configuration

**ID:** 3.1
**Severity:** High
**Category:** Security
**Status:** Closed

## Affected Files
- `sentinel/web/routes.py`

## Description
Configuring printer IP allows Server-Side Request Forgery (SSRF). The printer IP setting accepts arbitrary IP ranges (including link-local or loopback addresses), allowing the application to connect to internal services.

## Evidence
- No validation blocks setting printer IP to localhost (127.0.0.1) or internal address ranges like 169.254.169.254.

## Impact
- An attacker with configuration access can scan local network endpoints or query cloud metadata services.

## Acceptance Criteria
- [x] Restrict printer IP field to valid external LAN IP or hostnames, blocking loopback and link-local ranges
- [x] Add unit tests for SSRF address ranges
- [x] Tests pass
- [x] Coverage maintained ≥ 85%
