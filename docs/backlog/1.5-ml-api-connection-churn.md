# TCP Connection Churn for ML API Inferences

**ID:** 1.5
**Severity:** Medium
**Category:** Performance
**Status:** Closed

## Affected Files
- `sentinel/ml/client.py`

## Description
Inference client creates a new HTTP connection for each ML API request, causing TCP connection churn.

## Evidence
- MlClient initializes an HTTP client per request rather than reusing a persistent client session.

## Impact
- Increased inference latency and CPU overhead from repeatedly negotiating TCP and TLS handshakes.

## Acceptance Criteria
- [x] Use a persistent client session or connection pool for ML API calls
- [x] Test that connections are pooled and reused across multiple inference requests
- [x] Tests pass
- [x] Coverage maintained ≥ 85%
