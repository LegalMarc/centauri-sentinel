# Unbounded MJPEG Stream Proxying for Web Dashboard

**ID:** 4.5
**Severity:** Medium
**Category:** Performance
**Status:** Closed

## Affected Files
- `sentinel/camera/mjpeg.py`

## Description
The MJPEG camera stream proxy has no limits on duration or active stream count, consuming high bandwidth and CPU.

## Evidence
- stream_proxy does not limit stream count or connection time.

## Impact
- Low-power hosts run out of memory or CPU when multiple dashboard pages are open.
