# Database Write Lock Starvation Caused by High-Frequency Heartbeats

**ID:** 1.6
**Severity:** Medium
**Category:** Performance
**Status:** Closed

## Affected Files
- `sentinel/db/repo.py`

## Description
High-frequency watchdog updates / heartbeat writes to the SQLite database cause write lock contention and starve other database operations.

## Evidence
- Heartbeat ticks perform synchronous write queries at short intervals, locking the single-writer database.

## Impact
- Delay in recording critical detection events or dashboard load performance due to database lock starvation.

## Acceptance Criteria
- [x] Reduce heartbeat write frequency or optimize lock timeouts
- [x] Verify concurrent read/write queries complete without timeout during active heartbeats
- [x] Tests pass
- [x] Coverage maintained ≥ 85%
