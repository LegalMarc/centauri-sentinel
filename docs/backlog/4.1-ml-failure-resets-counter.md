# ML API Network Failures Silently Reset Consecutive Detection Counter

**ID:** 4.1
**Severity:** Medium
**Category:** Maintainability
**Status:** Closed

## Affected Files
- `sentinel/watcher/loop.py`

## Description
Transient network failures to the ML API return score=0 and silently reset the consecutive detection counter, masking ongoing print failures.

## Evidence
- Exception handler in watcher loop resets consecutive detection count on ML query errors.

## Impact
- Failure to pause a print if network glitches occur during a spaghetti event.

## Acceptance Criteria
- [x] Retain consecutive confirmation count on transient ML failures
- [x] Only reset count on a verified negative detection frame
