# Orphaned Snapshot Files on Disk Deletion Failures

**ID:** 2.9
**Severity:** Low
**Category:** Bugs
**Status:** Closed

## Affected Files
- `sentinel/watcher/loop.py, sentinel/db/repo.py`

## Description
Failed disk deletions during database record purges leave orphaned snapshot image files behind.

## Evidence
- File deletion failures (e.g. FileNotFoundError, PermissionError) are caught but no cleanup retry or logging is handled.

## Impact
- Gradual buildup of orphaned files on disk, wasting storage space.

## Acceptance Criteria
- [x] Verify all files are deleted when DB rows are purged, with appropriate logging on failure
- [x] Implement fallback disk-level directory cleanup
