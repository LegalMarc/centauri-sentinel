# Stop Command Timeout Resets Auto-Stop Timer

**ID:** 4.4
**Severity:** Medium
**Category:** Maintainability
**Status:** Closed

## Affected Files
- `sentinel/watcher/loop.py`

## Description
When a print stop command times out, the auto-stop timer resets, delaying cancellation.

## Evidence
- Timeout handler resets timers instead of marking command failed.

## Impact
- Print continues running despite cancellation requests.
