# CLI Host/Port Overrides Ignored by Downstream Components

**ID:** 2.1
**Severity:** Medium
**Category:** Bugs
**Status:** Closed

## Affected Files
- `sentinel/__main__.py`

## Description
Host and port values passed as command-line arguments are not forwarded to the ASGI server configuration and are ignored.

## Evidence
- CommandLine options parsed in __main__.py are not passed down to settings overrides or uvicorn configuration.

## Impact
- Inability for users to customize dashboard port or bind host via command-line flags.
